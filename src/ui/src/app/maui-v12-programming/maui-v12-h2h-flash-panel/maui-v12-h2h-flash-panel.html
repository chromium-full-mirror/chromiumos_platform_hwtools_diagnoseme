list How to flash the H2H firmware
  1. Copy the H2H image (.bin, 8704 bytes) to this folder on the station: {{ directory || '…' }}
    The station creates this folder. Images made by prepare_raw_flash.py are named prolific_raw_<number>_<serial>.bin.
  2. Click Refresh, then select the file in the list.
  3. Optional: check Change serial number and type the new serial (MAUIV12H + 8 digits). The file itself is not changed.
  4. Click Flash H2H Firmware and wait for PASSED. Do not unplug the Maui while it flashes.
  5. If the serial number changed: provision the MCU serial number (card below) and run the H2H SPI check again.
