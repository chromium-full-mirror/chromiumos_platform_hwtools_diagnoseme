Maui v1.2: Programming & Recovery

Help page for re-programming Maui v1.2 boards (ITE IT82002); this is not part of the guided test flow. The MCU can be programmed in two ways:

  • MCU App update over USB (RW bootloader): replaces only the App; bootloaders and the serial number stay.
  • Full MCU image (1 MiB) over USB-UART with itecomdbgr: rewrites the whole flash, also on a blank board; the serial number has to be provisioned again.

The H2H bridge firmware (PL27A1 SPI flash, holds the unit serial number) can be flashed too, optionally with a new serial number.
